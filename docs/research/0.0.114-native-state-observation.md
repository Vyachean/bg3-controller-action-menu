# v0.0.114 native controller state observation milestone

**Target:** Xbox App PC BG3 1.8.910.0, no Script Extender, no native code,
no dynamic installer or Game.pak generation. **Status:** experimental
read-only XAML observation; **not** a gameplay correction or runtime proof
until an operator tests the published prebuilt package.

## Why one bundled diagnostic release

v0.0.113 reported seven game behaviors that static CI cannot infer from
BG3's original but uncompiled XAML. PR #179 mapped the five B routes
but cannot establish whether `ActionCancelCommand`, `CloseWidget` or
`ClearSingleHotbarCommand` rolls back BG3's pending metamagic task.
PR #180 removed two competing sidebar direction owners, but native
`LSGrid` endpoint navigation remains in-game unverified.
Resource-tabs call `FilterActionResourceCommand` and provide native
`VMHotBarSlot`; no source yet proves a tab-level-specific `VMUpcast`
execution object to suppress the second native level choice.

**A build artifact is not an installable release.** Install using the
unchanged universal VBS only after GitHub shows a published non-draft
`v0.0.114-native-state-probe`, all seven required assets, and the
Release workflow passes its real public launcher resolution.

## Passive observer

The package temporarily includes one compact dark readout at the
top-right of the ActionRadials view. It is not full-screen, focusable,
hit-testable, clickable, a logger or a diagnostic remote service.
It binds existing properties using ordinary XAML TextBindings; no
new input bindings, commands, timers, event handlers, VM writes,
external code or user data storage are added.

| On-screen label | Source / meaning |
| --- | --- |
| Provider | CAM provider marker; blank means ordinary resource mode |
| CAM phase | Local presentation phase marker; not BG3 state |
| BG3 metamagic | BG3-owned `PlayerCharacterProperties.MetamagicActive` |
| Resource | Selected BG3 resource preview's `ActionResource.Name` |
| BG3 filter | `CurrentSingleHotbarFilter`, if exposed |
| BG3 upcast | Native `IsSelectingUpcastedSpell` |
| BG3 variants / BG3 throw | Native nested action flags |
| Nested slots | `SingleHotBar.SlotList.Count` |
| Sidebar / Grid enabled | Which of CAM's two list surfaces can receive focus |
| Sidebar / Grid focus | SlotType at each list's native LocalFocus |
| Dispatch slot | The `ActionRadials.Tag.SlotType` passed to UseSlotCommand |
| Slot CanUse / Slot modified | Native VMHotBarSlot.CanUse / Content.IsModified |
| Spell task | `CurrentSpellTask.TargetingType`; blank is **unknown/null**, not evidence of successful rollback |

`TextBlock.Text` is not an authoritative serialized engine trace.
If a binding is blank or fails to update on an engine event, document
that as unknown rather than conclude that BG3 cancelled the effect.
When Actions closes the panel disappears. Reopen Actions to inspect
whether game-owned `MetamagicActive` remains selected.

## Exactly one combined operator run

Run this **once**, on a game save containing a sorcerer/metamagic and
a castable level-IV spell. If a particular capability isn't on that
character, note `not tested`, don't create extra characters or
request a separate micro-test.

1. **Metamagic selector and D-pad endpoint.** Open Actions by RB,
   switch to the metamagic tab, and note `BG3 metamagic`,
   `CAM phase`, `Sidebar focus` and `Grid enabled`.
   Press Down beyond the last real modifier, then Up once. Record
   whether native ring, tooltip and actual focus remain on a valid
   modifier. The readout's SlotType alone cannot identify a specific
   modifier — visual agreement remains important.
2. **Select a modifier, then B.** Press A on one available modifier.
   Check BG3 metamagic, CAM phase, which list is enabled and the
   dispatch slot. In the spell grid, note whether visibly dimmed
   incompatible spells are still selectable; do not cast one merely
   to test the filter. Press B once; check whether the sidebar ring,
   real focus and tooltip agree and whether BG3 metamagic is still
   active.
3. **Close without casting.** Reenter the spell-choice phase if
   needed and close Actions without selecting a spell. Reopen once.
   Check `BG3 metamagic` plus native glow. This distinguishes a
   local CAM phase reset from an actual BG3 cancellation. Do not
   infer a successful rollback from disappearance of the panel.
4. **Resource level IV.** Select IV and a level-I spell that can be
   upcast. Observe the `BG3 upcast` flag before and after A, and
   whether BG3 presents a second level selector. Press B to exit
   rather than spending spell slots merely for diagnostics.

A normal LB/RB entry observation, footer overlap, cost preview and
weapon-hold hints can be recorded in the same session if already
visible, but they do not justify a separate release or test.

**Evidence:** one brief written result plus at most a few screenshots
of the readout at the relevant transitions is sufficient. Avoid
manually transcribing all seventeen values. Do not capture saves,
account identifiers, logs, or private game files.

## Expected output / limits

The panel exposes **observed current values**, not engine event history.
It cannot prove native cancel command effects that happen only after
the widget disappears. It cannot prove that dimmed spell content is
blocked by an executable provider. It cannot infer the exact upcasted
slot consumed by casting. If these questions remain ambiguous after
one run, classify them as technically unobservable under the current
no-DLL/no-SE UI-only contract. Do not fix them with invented commands.

## Mandatory retirement

`tools/audit-state-probe.py` asserts:
- exactly 17 explicitly allowlisted read-only Text binding paths;
- non-focusable, non-hit-testable, statically bounded presentation;
- no input handler, command, state write, button or event route;
- negative-mutation rejection;
- the panel appears **only** when VERSION is exactly
  `0.0.114-native-state-probe`.

The next nondiagnostic VERSION must remove the whole
`CAM_StateProbePanel`; static CI rejects retaining it. This diagnostic
version is not accepted as final gameplay behavior.
